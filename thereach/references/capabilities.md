# 平台能力与边界

平台总览与验证范围见仓库 [README](../../README.md)。状态含义：工具发现是本地声明，真实样本取得文本才是动作证据；搜索命中、正文、描述、字幕、评论、OCR和图片分类分别判定。

- 抖音：优先已验证连接器，再读现有专用浏览器中的目标视频描述；公开 HTML / yt-dlp 为有限备用。搜索优先可选本机 `china-read`，缺少时尝试站外索引；不保证精选推荐流。评论仅当前页面加载样本。
- 小红书：复用 Reach 搜索、笔记文字和已加载评论。文字取得不代表已看懂图片。访问签名仅用于读取，导出规范 URL。
- B站：BV 读取复用 Reach，旧 AV 用公开 view 元信息解析。字幕/评论复用现有 OpenCLI 浏览器适配器；字幕接受 URL 的 p 参数，但多P线上样本未验收。
- 微信公众号：现有专用浏览器的 js_content → 公开 HTML → Reach reader；搜索为站外索引，没有通用任意文章评论接口。
- YouTube：Reach 元信息/字幕与 yt-dlp 有限评论；官方 Data API 需配置。API key 不等于任意视频字幕权限。
- X：Reach 线程/搜索，或显式授权的官方 API；评论只包含返回的实际回复。

所有路线遇到验证码、登录要求、权限不足或限流必须停止。用户本人处理后才能恢复，不换后端绕过。素材上传、付费 API 和外部模型调用需要显式授权及预算。

目前验证主要覆盖 macOS ARM64；Browser Bridge 复用依赖上游内部接口。系统 Vision 的 OCR 与标签分类在本机执行；远端图片完整链路、云端 ASR、原生 AI 与官方 API 线上能力不宣称已验证。


2026-11-15：B站与本地文件新增 Apple SpeechAnalyzer 中文本机 ASR。显式 --transcribe 优先字幕；无字幕则获取浏览器独立音轨，拒绝试看/付费和不匹配素材。一个约 21 分钟 B站样本端到端通过；原生中文资源预检、时间戳和缓存均已验收。没有上传、付费调用或下载模型，但有数字、人名识别错误；样本不保证任意视频或设备可用。
